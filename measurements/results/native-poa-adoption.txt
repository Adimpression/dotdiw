Change
  POA now derives all operation contracts, shared types, calls, external
  dependencies, provenance and exact participation scopes from the source.
  Native operationContracts and operationContractTypes replace the legacy
  per-step operation blocks and operationTypes. complete-idl.py is removed.
  generate-project.py only attaches application manifests, projection
  descriptions and change records, and generates Python records, doors and the
  adapter starter. Guards and a fresh native-derivation comparison protect
  every other native IDL section; legacy authoring annotations are refused.

  Compared with the pre-adoption source: all 55 operation IDs and kinds, 139
  type IDs, record fields and order, 112 call edges, external calls and
  dependencies are preserved. There are 129 record types and 26 interface
  bindings. Six read operations are query-only; observing a formula no longer
  claims to write its authoring lifecycle transition. Praxis and the POA
  mirror agree. Participation and timing reflect actual backend crossings.

  Runtime Python AST differs only in the release constant, now 4.2.1. The
  project version, lockfile and version-output checks agree. Tracker interface
  4 and digest e29ce5a9be895e93 are unchanged.

Wire compatibility
  Native gRPC generation receives the released field-number registry plus:
    --json-list-map type.forward-to-the-tracker-response:answers
  The released wire field stays repeated JSON strings; canonical domain IDL
  remains a list of maps. Native metadata records the domain type and encoding.
  Native conform grpc-signatures does not forward the encoding selector; this
  proof uses native generate, Buf compilation and actual-server descriptor
  comparison instead. It does not claim that helper passed or that generated
  metadata itself enforces runtime validation.

Reproduction
  Set DOTDIW_POA to the qualified build and follow version 8 of
  check-promise-artifacts.formula.toml. Generation/static checks used Python
  3.12.16, Ruff 0.17.3 and mypy 2.4.1. Full tests used Python 3.14.3, protobuf
  7.35.1 and grpcio 1.80.0, with Buf and protoc 25.1 available. Test-only
  dependencies were installed in an isolated environment.

  "$DOTDIW_POA" validate --model poa/product-model.yaml
